How to switch scenes in unity

First, Scenes that you want to use need to be added to the scene manager.
Its under: File → Build Profiles → Open Scene List

Option 1:

public void onButtonPressed()
{
SceneManager.LoadScene(“Level1”);
}

This works, but you have to rely on the name of the scene. If you ever rename the scene to something else,
it will stills earch for Level1.
If you are doing a bigger project, try:

Option 2:

First, open your scenes .meta file, and grad the GUID. This is a unique identifier that never changes (unless you delete the scene).

private string guidLevel1 = “theGUIDYouCopiedEarlier”;

public void onButtonPressed()
{
private string scenepath = AssetDatabase.GUIDToAssetPath(guidLevel1);
SceneManager.LoadScene(scenepath);
}

You can obviously change the structure further to fit your project.
Most importantly, you can now move the scene to a different folder, or even rename it, and LoadScene will still find it.
